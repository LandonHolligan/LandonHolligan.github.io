# Engineering Portfolio Starter

A simple static engineering portfolio intended for GitHub Pages.

## Before publishing

1. Replace `YOUR NAME`.
2. Replace the email, LinkedIn, and GitHub links.
3. Put your resume at `assets/resume.pdf`.
4. Replace project placeholder images with your own CAD, FEA, hardware, and testing visuals.
5. Replace placeholder project descriptions with concise statements of:
   - problem / requirements
   - your individual contribution
   - engineering methods
   - quantitative results
6. Remove any project or information you are not permitted to publish.

## Publish on GitHub Pages

Create a repository named `<your-github-username>.github.io`, upload these files to the repository root, and configure GitHub Pages to publish from the main branch/root if necessary.

The homepage file must remain named `index.html`.
